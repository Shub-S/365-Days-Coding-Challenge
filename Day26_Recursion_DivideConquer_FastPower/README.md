# Day 26 - Divide and Conquer: Fast Exponentiation

## Problem
Compute x^n mod (10^9 + 7) using divide-and-conquer (binary exponentiation).

## Concepts Covered
- Divide and Conquer beyond sorting
- Fast exponentiation (halve exponent, square, conditionally multiply)
- Modular arithmetic to prevent overflow
- O(log n) vs O(n) complexity comparison

# Day 33 - Merge Two Sorted Lists & Merge K Sorted Lists Intro

## Problem
Merge two sorted linked lists into a single sorted linked list.

## Concepts Covered
- Two-pointer merge technique (from Merge Sort, applied to linked lists)
- Dummy node technique for simplified list construction
- Merge K Sorted Lists: sequential O(K*N) vs heap-based O(N log K) (conceptual)
- Pointer relinking (no new node allocation needed)

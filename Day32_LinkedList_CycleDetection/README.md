# Day 32 - Linked List Cycle Detection (Floyd's Algorithm)

## Problem
Detect if a linked list has a cycle, and find the cycle's starting node.

## Concepts Covered
- Floyd's Cycle Detection (Tortoise and Hare)
- Fast/slow pointer pattern (distinct from two-ends two-pointer)
- Two-phase algorithm: detect meeting point, then find cycle start
- O(1) space cycle detection vs O(n) HashSet approach

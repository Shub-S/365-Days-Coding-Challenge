# Day 23 - Recursion: Backtracking Introduction

## Problem
Generate all subsets (power set) of {1, ..., n} using backtracking.

## Concepts Covered
- Backtracking template: choose, recurse, undo
- Include/exclude decision tree pattern
- Power set generation (2^n subsets)
- Common pitfall: storing references vs copies of mutable state

## Files
- Main.java

## Complexity
Time: O(n * 2^n) | Space: O(n) recursion depth

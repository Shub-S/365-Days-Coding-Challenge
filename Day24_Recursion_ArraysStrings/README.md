# Day 24 - Recursion on Arrays & Strings

## Problem
Recursively check if an array is sorted and find its maximum element.

## Concepts Covered
- Index-shrinking recursive pattern on arrays
- Short-circuit evaluation in recursive conditions
- Recursive (O(n) space) vs iterative (O(1) space) trade-offs
- Foundation for recursive tree/linked-list traversal

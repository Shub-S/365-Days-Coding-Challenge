# Day 25 - Combinations & Permutations Basics

## Problem
Generate all permutations of an array of distinct integers.

## Concepts Covered
- Permutations vs Combinations distinction
- Backtracking with used[] boolean tracking array
- Multi-choice branching (loop over all unused elements per step)
- Factorial (n!) growth vs subsets' exponential (2^n) growth

## Files
- Main.java

## Complexity
Time: O(n! * n) | Space: O(n)

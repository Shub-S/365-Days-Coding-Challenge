# Day 31 - Linked List Reversal (Iterative & Recursive)

## Problem
Reverse a singly linked list using both iterative and recursive approaches.

## Concepts Covered
- Three-pointer iterative reversal technique
- Recursive reversal (reverse rest, then attach self)
- "Save next before overwriting" critical pattern
- Space complexity: O(1) iterative vs O(n) recursive
